Predicting Mental Health Symptom Severity

We compared behavioral questionnaires, resting-state fMRI features, and multimodal data to predict continuous depression, anxiety, stress, and anhedonia severity using the Transdiagnostic Connectome Project.

Research question

Which data source provides the strongest out-of-sample prediction of mental-health symptom severity?

Main finding Behavioral features were consistently the strongest predictors.

Project overview

From symptom questionnaires and brain connectivity to continuous severity prediction

The project focuses on symptom severity rather than diagnosis, allowing the models to capture variation within and across traditional diagnostic groups.

Method

A reproducible comparison across modalities

Every target uses a matched participant cohort across modalities. Feature reduction for regional imaging data is fitted inside each training fold to reduce leakage risk.

Fair comparisonSame cohort and deterministic 80/20 split within each outcome.
Repeated validation5 stratified folds × 3 repeats on the training set.
Imaging reductionSelectKBest plus PCA applied inside training/CV folds.
Final metricsMAE, RMSE, R², variability, sample size, and feature counts.

Key results

Behavioral data carried most of the predictive signal

The strongest behavioral models outperformed imaging-only models for all four outcomes. Adding the current fMRI representation generally did not improve on the strongest behavioral-only model.

01Behavioral models led

Questionnaire features produced the strongest repeated-CV performance.

02Imaging was weak alone

Imaging-only R² values were near or below zero.

03Multimodal ≠ automatically better

More features did not translate into better prediction.

04Anhedonia was hardest

SHAPS showed the weakest and least stable generalization.

Cross-category analysis

How do cross-category symptom domains influence prediction?

Each outcome begins with its own symptom domain as a baseline. The charts show how repeated cross-validation R² changes when related domains are added.

Takeaway

Related symptom domains sometimes improved prediction, but the size and direction of that contribution differed substantially by outcome.

Benefits & challenges

Useful for research—careful in interpretation

Benefits

  • Improved research: efficiently compares behavioral and neuroimaging signals.
  • Cross-domain insight: quantifies how symptom domains contribute to one another.
  • Decision support potential: may eventually complement professional assessment and monitoring.
  • Transparent exploration: an interactive Streamlit dashboard makes results accessible.

Challenges

  • Not diagnostic: predictions must not replace licensed clinical evaluation.
  • Generalizability: the sample comes from one research dataset.
  • Imaging limitations: the current fMRI representation added little out-of-sample value.
  • Privacy & ethics: mental-health and neuroimaging data require careful handling.
Responsible use

This project is for research and education. Its predictions are not medical diagnoses and should not be used to make clinical decisions about an individual.
